# Support

RustJSI is experimental and unpublished. There is no support SLA, supported
engine/host tuple, or production-use commitment at this stage.

## Where to start

1. [`README.md`](README.md) for status and workspace layout
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) for the public technical direction
3. [`ROADMAP.md`](ROADMAP.md) for planned phases
4. [`CONTRIBUTING.md`](CONTRIBUTING.md) for local development
5. [`SECURITY.md`](SECURITY.md) for vulnerabilities

## Questions and bugs

When a public issue tracker is available, use the repository issue forms.
Until then, do not assume that a ticket tracker is monitored.

Do not file public issues for unresolved vulnerabilities.

## What is not supported yet

- production application debugging;
- engine-specific integration support;
- React Native module support;
- performance, zero-copy, or compatibility guarantees;
- treating workspace compilation as runtime validation.
